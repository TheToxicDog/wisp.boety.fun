Architecture layers

  1. PresentationSearch bar, navigation and an isolated iframe or about:blank window
  2. InterceptionScramjet service worker rewrites HTML, CSS and JS; location, top and cookies virtualized in IndexedDB
  3. Transport bridgebare-mux + epoxy WASM run TLS in-browser and pack requests into Wisp frames
  4. Edge ingressCloudflare Anycast terminates public SSL and shields the origin IP
  5. Origin relayNginx → wisp-js demultiplexes streams into outbound TCP/UDP sockets
